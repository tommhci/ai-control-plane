# CLAUDE.md

Claude Code entry point for this repo. The operating contract lives in
**AGENTS.md** — read it first (Session Start Checklist, Change Flow,
protected paths, profile truth table).

Then, before destructive or governance-adjacent actions:
1. `PROJECT_STATUS.md` — Current snapshot (what is already decided/REsolved).
2. `docs/cross-tool-lessons.md` — cross-tool lessons registry (L1-L6, U4).
3. The findings register in `docs/audits/` — check open findings before repair/deletion work.

Rationale: this file exists so the control plane's Claude entry is
version-tracked (baseline-integrity standard, 2026-08-11 node) — a fresh
clone must not silently lose the Claude on-ramp.
